# Skyline 0.0.3 — Windows testing release

Download **Skyline-v0.0.3-windows-x64.zip**, extract it, and run **Skyline.exe**.
The version is visible in the header, window title and About window. No installer
is needed; OpenGL 2 or newer is required. DATs and ROMs are supplied by the user.

This release includes recursive DAT-folder intake, catalog-driven system and
variant awareness, an indexed reference database, header diagnostics, and
streaming verification of ROMs inside ZIP files. Right-click a row to show its
file (or containing ZIP) in Explorer or copy its path.

The Windows executables are the exact checked 0.0.3 development build, promoted
to Releases without recompilation. Package documentation is corrected; executable
checksums remain unchanged. The download has a SHA-256 sidecar and an internal
checksum manifest.

This is a read-only testing prerelease. Organization, copy/move, recovery,
disc/7z/RAR adapters and N64 byte-order conversion are unfinished. Native Windows
picker, Explorer, scaling, accessibility and responsiveness acceptance remain
pending. Windows CI validates builds and synthetic tests, not those GUI checks.
Builds are unsigned. The application code license awaits owner selection; a
dependency inventory is included and full notice review remains open.
